Library - everything you've ever done, in one place

Experience, Projects, Education
Add once in the Library tab. Every field has a "Used in N versions" note so you can see the impact before editing it.
Skills, Skill Sets
Individual skill categories, plus named bundles of them (e.g. "Data role") you can pick as a group when building a version.
Summaries, References, Custom Sections
A pool of reusable summary paragraphs, references, and any extra section (Certifications-style, Publications-style, or your own).
Publications, Certifications
Dedicated, citation-style Library kinds with their own fields (authors/venue, issuer/credential ID).
Positions
Add multiple roles under one Experience entry, or multiple sub-entries under one Custom Section - each with its own dates and bullets, each independently include/excludable per version.
Sub-bullets
One level of indented bullets under any bullet, for supporting detail.
Bullet & position reordering
Move-up/move-down arrows next to every bullet, sub-bullet, and position - in the Library, the editor checklist, or the entry-edit modal.
Tags
A shared, renameable label pool (Settings-managed) applied to bullets and skill categories - the basis for "Fill in with tag" below.

Versions - one tailored resume per job

Create / duplicate / delete
A version is a selection from your Library plus its own style - nothing is copied, everything updates if the Library entry changes.
Selection checklist
Check which entries, bullets, and positions print, and reorder them - the order here is the print order.
Fill in with tag
Instantly include everything tagged for a specific role, plus switch to a summary/skill set carrying that tag.
Only-this-version overrides
Freeze one field, one bullet, or one position's wording for a single version - from the entry-edit modal's "Save changes to" choice - without touching the shared Library.
Section order & headings
Reorder whole sections and rename their printed heading, per version.
Standalone versions
Import a resume file as a fully separate, private version with its own embedded content - doesn't touch or read from your shared Library.
Trash
A deleted version stays recoverable (Dashboard → Trash) until you restore it or empty the trash yourself.
Undo / redo
Cmd/Ctrl+Z and Shift+Cmd/Ctrl+Z work in the Library and the Editor.

Style & export

Style panel
Font (Times, Arial, Georgia, Calibri, Cambria, Garamond, Computer Modern), sizes, margins, bullet marker, page size, and per-field bold/italic toggles.
Inline **bold**/*italic*
Wrap any word in a bullet with `**word**` or `*word*` to format just that word.
Live preview
An accurate, paginated, zoomable preview - what you see is genuinely what the export produces.
Download PDF / DOCX
Real vector-text exports (selectable, ATS-readable) - not screenshots.
Cover Letter
A separate, quick cover-letter builder (Modern/Classic/Minimal looks) with its own PDF export.

Account

Preferences
Account-wide defaults (style, section order, references mode) applied automatically to every new version.
Import Resume
Paste your existing resume into an AI chatbot using the built-in prompt, then bring the result in - Replace everything, Review & merge, or import as a Standalone version.
Export Shelf
Download a full backup of your account (Library + all versions) as JSON, from Settings.
GitHub Backup
Connect a GitHub repo (Settings) for an automatic, one-way push of your Library and versions after every save.
Theme
Light/dark toggle in the topbar - the choice follows you across the app and these help/status pages.
Change password, sign-in options
Email/password, Google, or GitHub sign-in; change your password from Settings at any time.

AI assistant (MCP)

Connected Apps
Connect Claude Code, Claude Desktop, or another MCP-compatible AI tool directly to your account (Settings → Connected Apps).
Edit by conversation
Once connected, ask your AI assistant to read your Library, add bullets, tailor a version, or export a PDF - changes show up in the real app immediately.
Page-layout awareness
Your assistant can check exactly which section landed on which page before or after trimming content, instead of guessing.
